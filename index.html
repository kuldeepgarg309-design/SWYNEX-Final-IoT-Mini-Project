Conceptual IoT Architecture

Sensor layer → Microcontroller (ESP32) → Wi-Fi / Network → Data storage / processing → Web dashboard and alerts

In a real deployment, sensors may measure environmental or electrical parameters. This project simulates readings in the browser and does not connect to physical sensors.

Project Limitations

  • All readings are randomly generated in the browser.
  • No physical sensors, transformer, ESP32, cloud service, or database are connected.
  • Alert thresholds are illustrative and are not validated protection settings.
  • This dashboard is an educational prototype, not a safety-critical monitoring or protection system.
